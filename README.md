# 3d-Flipname-generator
Flip Name 3D: how to use it

Open the page.
Type the first name and the second name.
If one name is shorter, tap an emoji (❤️ ⭐ 🌸 🔥) to fill the gap. You can also type an emoji yourself anywhere in a name, for example sr⭐ivel.
Set the letter height in mm (30 is a good start) and pick the colors for the letters and the base.
Tap Generate.
Drag to rotate, pinch or scroll to zoom, and double-tap to reset. Use the Name 1 and Name 2 buttons to check both sides.
To print, tap Download STL. Unzip it if it arrives as a .zip, open the .stl in Bambu Studio (File, Import) or any slicer, then slice and print.
To edit, tap Editable files (Tinkercad / CAD), unzip it, and in Tinkercad choose Import and pick the .obj file with the scale at 100%.

Tips: capital letters work best, and a shorter name plus an emoji is fine.
