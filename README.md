# Flip Name 3D

Type two names and get a 3D dual-name illusion that you can 3D print.
One name reads from one side, and the other name reads from the opposite side.

## How to use it

1. Open the page.
2. Type the **first name** and the **second name**.
3. If one name is shorter, tap an emoji (❤️ ⭐ 🌸 🔥) to fill the gap. You can also type an emoji anywhere in a name, for example `sr❤ivel`.
4. Set the **letter height** in mm (30 is a good start) and pick the colors for the letters and the base.
5. Tap **Generate**.
6. Drag to rotate, pinch or scroll to zoom, and double-tap to reset. Use the **Name 1** and **Name 2** buttons to check both sides.
7. To print, tap **Download STL**. Unzip it if it arrives as a `.zip`, then open the `.stl` in Bambu Studio (File > Import) or any slicer, slice, and print.
8. To edit, tap **Editable files (Tinkercad / CAD)** and unzip it. In Tinkercad choose **Import**, pick the `.obj` file, and keep the scale at 100%.

## Tips

- Capital letters work best.
- A shorter name plus an emoji works fine.
- Check both sides in the viewer before printing.
- Also, use any textures, like fuzzy skin, while 3D printing for better results. 
- In the model, there may be some stair-like designs. That's because of pixel limitation. But that texture may be nice for the model.
