# Flip Name 3D

Type two names and get a 3D dual-name illusion that you can 3D print.
One name reads from one side, and the other name reads from the opposite side.

## Features

- Two names in, one 3D model out, with a live 3D viewer
- Emoji support: quick fill buttons plus a picker with 48 emojis (hearts, stars, flowers, animals, objects)
- Color for each letter and each emoji, plus a base color
- Surface textures: Fuzzy skin, Fine grain, Ribs and Bumps, with adjustable depth and size
- Smooth surface and a widened footing under every letter, so letters stay attached to the base
- STL download, ready for Bambu Studio or any slicer
- Editable files for Tinkercad and other CAD tools (OBJ, plus every letter as a separate part)
- Works on desktop and phone

## How to use it

1. Open the page.
2. Type the **first name** and the **second name**.
3. If one name is shorter, tap an emoji to fill the gap. You can also open **More emojis** and tap any emoji to insert it where you are typing, or type an emoji anywhere in a name, for example `JA❤NANI`.
4. Set the **height** in mm (30 is a good start) and pick the **base** color.
5. Tap **Generate**.
6. Open **Color each letter** and pick a color for every letter or emoji. Use **All letters** to set one color for everything.
7. Open **Texture**, choose a type, and adjust **Depth** and **Size**. Leave it on Smooth for a clean finish.
8. Check the model in the viewer:
   - Drag to rotate, pinch or scroll to zoom, double-tap to reset.
   - Use **Name 1**, **Name 2** and **Top** to check each side.
9. To print, tap **Download STL**. Unzip it if it arrives as a `.zip`, then open the `.stl` in Bambu Studio (File > Import) or any slicer, slice, and print.
10. To edit, tap **Editable files (Tinkercad / CAD)** and unzip it. In Tinkercad choose **Import**, pick the `.obj` file, and keep the scale at 100%.

## Printing in multiple colors

The STL is a single color. For different colors per letter:

1. Tap **Editable files (Tinkercad / CAD)** and unzip it.
2. In your slicer, import `letter-01.stl`, `letter-02.stl` and so on, together with `base.stl`.
3. If asked, load them as parts of one object.
4. Assign a filament color to each part. The readme inside the zip lists the color picked for each letter.

## Tips

- Capital letters work best.
- A shorter name plus an emoji works fine.
- Check both sides in the viewer before printing.
- Textures are built into the letters, so they appear in the STL. The base stays smooth.
- You can also try your slicer's own fuzzy skin setting on a smooth model.
